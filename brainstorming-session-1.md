# Joss Paper AR - Brainstorming Session

## Project Overview
**Date**: 2026-09-22  
**Status**: Early Concept Phase  
**Tags**: #app-idea #AR #cultural-tech #gamification #chinese-tradition

---

## Core Concept
An Augmented Reality app that replaces physical joss paper burning with a digital/AR experience, evolving the tradition one step further into abstraction.

### Historical Evolution
1. **Ancient Era**: Emperors and nobility buried valuables with ancestors in tombs
2. **Common Practice**: Poorer civilians burned joss paper as an abstract replacement
3. **Future Vision**: AR/digital abstraction of the ritual

## Key Discussion Points

### 🎯 Core Experience & AR Mechanics

### 🎯 Core Experience & AR Mechanics (Updated)
- **AR Flow**: 
  - Users travel around and discover objects of significance (souvenirs, buildings, places)
  - Snap photos/videos of these items
  - Select and "cartoonize" the object to make it more abstract/digital
  - **Burning Ritual**: AR fire appears on reality, user swipes to throw cartoonized object into the fire
- **Key Insight**: This transforms the experience from passive memorial to active journey of discovery and remembrance

### 🎮 Gamification & "Economy of Attention"

### 🎮 Gamification & "Economy of Attention" (Updated)
- **AR Fire Collection**: Purely cosmetic - bragging rights, exchangeable designs, earn through usage or real money
- **Points System**: % of value as they burn to honor ancestors, or spend real money
- **Virtual Temple**: Explorable 3D space to decorate like ancestral temple but modern/futuristic
- **Throw Quality Multipliers**: 1.2x, 1.5x, 2x based on throw accuracy (not too harsh)
- **Location-Based Value System**:
  - "Home ground" = where user spends most time burning
  - Venturing elsewhere = high value initially, decreases with repeated burns in same vicinity
  - Keep-alive time for location values to prevent exploitation
- **Privacy & Location Tracking**: GPS or signal triangulation, data stored only for ~4 blocks radius
- **Monetization**: Battle pass system coming in later versions
- **MVP Features**: Points exchange for collectables + ranking board/leaderboard (competition sells!)
- **User Onboarding**: Tutorial showing object capture → cartoonization → burn → leaderboard introduction
- **Leaderboard Design**: Like Duolingo - show users within similar skill levels to prevent disengagement
- **Streak System**: Daily login streaks with bonus points for longer streaks (similar to other games)
- **Burn Limits**: No forced daily burning to maintain value and reduce server load
- **Alternative Points**: Users can purchase/exchange standard items (bundles of cash, gold bars) with fixed values when they have nothing to burn
- **Progression**: "Tribute Points" - users know they're progressing when their tribute amount increases on leaderboard
- **Animation Quality**: Flashier animations for higher value items - key to user satisfaction
- **Key Technical Priority**: Cartoonization style - must get the style right
- **Target Audience**: Late 40s-50s, family pass-down tradition, growing over generations
- **Advertising**: Respectful, family-oriented (travel, shopping, government propaganda) - no sexual/gambling content

### 🎮 Gamification & "Economy of Attention" (Updated)
- **AR Fire**: User-buyable AR object, fixed position on phone (like Pokémon GO's catch mechanic)
- **Throwing Mechanic**: Aiming element to make it feel like a game - precision matters!
- **Value System**:
  - Base value of the cartoonized object
  - Multiplier based on throw quality (aim accuracy)
  - Bonus for frequency of burning same item (diminishing returns?)
  - **Exploration Bonus**: Higher value when far from "usual home ground" - encourages travel and discovery
- **Shop System**: Users can buy different AR fire types/styles

  - Tourists/cultural enthusiasts

- **Cultural Consultation**: Need for consultation with cultural practitioners
- **Monetization**: How might this sustain itself financially?
